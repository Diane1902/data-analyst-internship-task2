# Task 2: Data Visualization and Storytelling
## Data Analyst Internship - Elevate Labs

## Objective
Create interactive visualizations that convey a compelling sales story 
using Power BI on the Superstore Sales dataset.

## Dataset
- **Source:** Kaggle - Superstore Sales Dataset
- **Size:** 9,800+ rows × 18 columns
- **Period covered:** 2015 - 2018

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)

## Dashboard Features
- 3 KPI Cards: Total Orders, Total Sales, Average Order Value
- Sales by Category (Bar Chart)
- Sales by Region (Pie Chart)
- Sales by Year (Line Chart)
- Top 10 Customers by Sales (Bar Chart)
- Sales by Segment (Treemap)
- 2 Slicers: Year and Region filters

## Key Business Insights
1. Technology is the highest selling category at $0.83M
2. West region leads all regions with 31.4% of total sales
3. Sean Miller is the top customer with $25K in sales
4. Sales dipped in 2016 but recovered strongly to $0.72M by 2018
5. Consumer segment dominates over Corporate and Home Office

## Interview Questions & Answers

**1. What is the importance of data visualization?**
Data visualization makes complex data easy to understand by presenting 
it in charts and graphs. It helps businesses spot trends, patterns and 
outliers quickly that would be hard to see in raw numbers.

**2. When do you use a pie chart vs bar chart?**
A pie chart is used to show proportions of a whole, like regional sales 
percentage. A bar chart is better for comparing values across categories, 
like sales across different product categories.

**3. How do you make visualizations more engaging?**
By using consistent colors, adding data labels, keeping charts simple 
and uncluttered, adding titles and context to each chart, and using 
interactive slicers so users can explore the data themselves.

**4. What is data storytelling?**
Data storytelling is the process of using visualizations and narrative 
to communicate insights from data in a way that is clear, compelling 
and drives decision making.

**5. How do you avoid misleading visualizations?**
Always start axes at zero, use appropriate chart types, avoid 3D charts, 
don't cherry pick data, and always provide context for the numbers shown.

**6. What are best practices in dashboard design?**
Keep it simple and uncluttered, use consistent colors, highlight key 
metrics with KPI cards, add slicers for interactivity, and focus on 
business insights rather than just showing data.

**7. What tools have you used for visualization?**
For this task I used Power BI Desktop to build an interactive dashboard 
with KPI cards, slicers and multiple chart types. I also have experience 
with Python libraries like Matplotlib and Seaborn.
